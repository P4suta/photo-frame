# Photo-frame

Pre-release photo framing with golden-ratio borders and Exchangeable Image File Format captions.

## Installation

```sh
cargo install --locked --path crates/photo-frame-cli
```

## Usage

```sh
photo-frame input.jpg -o framed.jpg
```
